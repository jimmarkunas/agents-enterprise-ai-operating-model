# Contributing to A.G.E.N.T.S.

A.G.E.N.T.S. is intended to be used, tested, challenged, adapted, and improved in real enterprise AI work.

## Report real adoption

If you used A.G.E.N.T.S. in a team, organization, workshop, governance review, product planning session, or production-readiness process, submit an **Adoption Report** under Issues.

Describe what you used, what decision or improvement it supported, and the outcome. If you have a public fork, implementation, project, article, or other supporting evidence, include the link in the report.

## Ask questions and share implementations

Use **Discussions** for community conversation:

- **Q&A** — questions about applying A.G.E.N.T.S.
- **Ideas** — proposed changes, extensions, or challenges to the model.
- **Implementations** — forks, adaptations, implementation patterns, and lessons learned.
- **Announcements** — official releases and major updates.

## Adapt the model

Fork the repository if you want to modify A.G.E.N.T.S. for your own implementation. You do not need to submit those changes back to the core model.

If your adaptation is public, share it in **Implementations** and, if you used it in practice, link it from your Adoption Report.

## Contribute to the core model

Open a Pull Request if you believe a change should become part of the core A.G.E.N.T.S. model.

Please explain:

1. What you changed.
2. What problem the change solves.
3. Why it improves the model.
4. Any real-world use, evidence, or examples that support the change.

Small, focused pull requests are preferred.

## Contribution principles

Contributions should make the framework clearer, more practical, more testable, or more useful in real production environments. Critical feedback is welcome.

Do not include confidential company information, private repositories, internal documents, credentials, personal data, or other material you are not authorized to share.
